# 닥터배 오프라인 세미나

오프라인 세미나에서 쓰는 자료 5종을 탭 하나로 묶은 페이지입니다.

- 공개 주소: https://baelab-create.github.io/drbae-off-line-seminar/
- 탭 순서: 고객 안내 / 입점 가이드·주문 / 제품 라인업 / 마이크로젝션 / 두피 케어
- 각 탭은 해당 사이트를 그대로 불러옵니다(원본을 고치면 여기도 바뀝니다).
- 숫자키 1~5, 좌우 화살표로 탭을 넘길 수 있습니다. `#3` 처럼 주소 끝에 번호를 붙이면 그 탭으로 바로 열립니다.

탭을 추가하거나 순서를 바꾸려면 `index.html` 아래쪽 `PAGES` 배열만 고치면 됩니다.
